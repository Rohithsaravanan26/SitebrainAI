# SiteBrain AI Agent Guidelines & Permanent System Rules

## Design & UI Constraints (STRICT & PERMANENT)
- **Product Definition**: Enterprise software for construction professionals (GCs, Subcontractors, Superintendents, BIM Managers).
- **Prohibited UI Elements**:
  - NO flashy AI demo websites
  - NO glassmorphism / backdrop blur
  - NO neon colors or bright saturated fills
  - NO purple gradients
  - NO glowing borders
  - NO oversized rounded cards
  - NO AI illustrations or generic hero mascot vector art
  - NO floating widgets or disruptive overlays
  - NO excessive whitespace
- **Design Inspiration**: Autodesk Construction Cloud, Procore, Jira, Linear, GitHub, Stripe Dashboard, Azure Portal, AWS Console.
- **Design Principles**: Professional, Industrial, Minimal, Information Dense, Fast, Accessible, Reusable, Responsive.
- **Color Palette**:
  - Primary: White, Slate, Navy
  - Accent: Construction Orange (`#F97316` / `#EA580C`)
- **Spacing**: Strict 8-point grid (`8px`, `16px`, `24px`, `32px`).
- **Typography**: Inter
- **Animations**: None unless meaningful (e.g. status transition indicators or loading state skeletons).

Every screen must look like software people use for work every day.
